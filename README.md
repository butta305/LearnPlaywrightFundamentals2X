# Learn Playwright Fundamentals 2X

This repository contains a simple Playwright test project demonstrating browser automation with Playwright.

## What’s included
- Playwright configuration
- Example browser tests
- Test reports and results folders

## Getting started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the tests:
   ```bash
   npx playwright test
   ```
3. View the HTML report:
   ```bash
   npx playwright show-report
   ```

## Notes
- The project uses Playwright’s default browser test setup.
- Dependencies are intentionally excluded from version control via the repository ignore rules.
